# Architecture Decision Records

Architecture Decision Records (ADRs) capture decisions that materially affect the structure, contracts, security model, or long-term extensibility of Raaya Git Deploy.

Use an ADR when a change:

- changes a baseline architectural decision,
- introduces a major dependency,
- changes the deployment safety model,
- changes transport contracts,
- changes how Git state is interpreted,
- changes credential/security behavior.

## Status Values

- Proposed
- Accepted
- Superseded
- Rejected

## Naming

```text
NNNN-short-decision-title.md
```

Example:

```text
0001-use-git-cli-as-source-of-truth.md
```
